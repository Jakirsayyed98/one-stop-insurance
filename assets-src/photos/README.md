# Original photos

Place licensed, high-quality originals here (at least 1600 px wide), named:

| File               | Used for                                   | Crop |
| ------------------ | ------------------------------------------ | ---- |
| `hero.jpg`         | Homepage hero image                        | 4:3  |
| `two-wheeler.jpg`  | Two-Wheeler card + Vehicle Insurance page  | 16:9 |
| `private-car.jpg`  | Private Car card + Vehicle Insurance page  | 16:9 |
| `commercial.jpg`   | Commercial card + Vehicle Insurance page   | 16:9 |

Then run `npm run images`. Until a photo is added, the site shows a matching vehicle illustration.

Use only photos you have the right to use commercially (your own photos, or stock licensed for commercial use). Avoid watermarked images and photos with readable number plates or identifiable people unless you have their consent.
