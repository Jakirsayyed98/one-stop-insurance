# Insurer logos

Add approved logo files here (SVG preferred; PNG/WebP also fine), e.g. `icici-lombard.svg`.
Then set `logo: 'partners/icici-lombard.svg'` for that insurer in `src/config/site.ts`.

Only use logos from the insurer's official brand/media resources or with written permission.
This README is not copied to the website.
